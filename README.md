# curæted paths website

Bilingual responsive website for curæted paths, a senior-led China outbound media and adtech growth consultancy.

## Routes

- `/` — English
- `/zh` — Simplified Chinese

## Local development

```sh
npm install
npm run dev
```

The contact form opens a pre-addressed message in the visitor's email client. The preview stores no form submissions or personal data.

## Verification

```sh
npm run build
npm run lint
npm run typecheck
```

Deployment is intentionally deferred until the redesign preview is approved.
